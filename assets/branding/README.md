# Icône Jerry

Un pointeur blanc dans un anneau de focus bleu, sur un carré anthracite aux
angles arrondis. Le dessin reprend les couleurs de l’interface et reste simple
à petite taille.

| Fichier | Usage |
| --- | --- |
| [jerry.svg](jerry.svg) | Original vectoriel éditable, canevas de 256 unités. |
| [jerry.png](jerry.png) | Export 1 024 × 1 024 avec transparence extérieure ; README et présentations. |
| [jerry.ico](jerry.ico) | Icône Windows avec dix résolutions : 16, 20, 24, 32, 40, 48, 64, 96, 128 et 256 pixels. |

Couleurs : fond `#202024`, anneau `#3B82F6`, pointeur `#F7F9FF`.
L’original est dessiné pour Jerry ; il ne reprend pas l’icône de MOUZZ.

Le projet WPF embarque le fichier ICO et l’utilise pour l’exécutable, la fenêtre
et la zone de notification. Pour changer le dessin, modifier le SVG et exporter
à nouveau les fichiers PNG et ICO en conservant les résolutions ci-dessus.
