# Applications à analyser

Déposer ici les archives et exécutables originaux de MOUZZ, avec leur version
et leur provenance. Le contenu de ce dossier reste local et est exclu de Git,
à l'exception de ce fichier.

REA peut analyser des fichiers macOS depuis cet environnement lorsque le format
et le moteur choisi le permettent. Exécuter l'application macOS et vérifier son
comportement réel nécessitent un environnement macOS.
