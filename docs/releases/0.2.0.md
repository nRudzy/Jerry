Jerry dispose maintenant d'un installateur Windows français, tout en conservant
son interface WPF et sa mascotte néon.

- **Jerry-Setup-0.2.0.exe** : installation pour votre compte, sans administrateur,
  dans `%LOCALAPPDATA%\Programs\Jerry`, menu Démarrer et désinstallation Windows.
- **Jerry-Windows-x64-0.2.0.zip** : alternative portable ; décompressez tout le dossier.
- **SHA256SUMS.txt** : empreintes des deux téléchargements.

Le runtime .NET 10 et les dépendances natives sont inclus. Le démarrage avec
Windows est facultatif et les mises à jour conservent votre choix. Une capture,
un décompte ou un travail ouvert bloque la maintenance ; une ancienne version
peut demander de quitter Jerry manuellement depuis son icône.

Les réglages, vidéos, sessions récupérables, modèles et outils téléchargés sont
conservés pendant les mises à jour et la désinstallation. Celle-ci désactive
seulement le démarrage automatique en plus de retirer les fichiers installés.

Les exécutables ne sont **pas signés numériquement** : « éditeur inconnu » ou
SmartScreen reste possible. Aucun changement de politique de sécurité,
PowerShell ou certificat n'est requis pour l'installation native.

Validation : 60 tests Core, 14 tests Windows, 14 contrôles natifs de maintenance
et 132 contrôles du cycle d'installation sur Windows jetable. Voir le
[rapport détaillé](https://github.com/nRudzy/Jerry/blob/main/docs/windows-installation.md).
