# Jerry Windows Implementation Plan

> **For agentic workers:** Use the implementation contracts below. Independent media and caption modules can be delegated with exclusive file ownership; the primary agent owns integration and final verification.

**Goal:** Deliver a runnable Windows application implementing the 37 documented Free + Pro requirements.

**Architecture:** Shared .NET core, WPF settings and overlay windows, Windows input hooks and magnification, independent recording and caption services. All recordings and recognition stay local.

**Tech Stack:** .NET 10.0.301, WPF, Win32, NAudio 2.2.1, FFmpeg, Whisper.net 1.9.0.

**Spec:** `docs/superpowers/specs/2026-10-27-windows-design.md` and `docs/mouzz-scope.md`.

## Global Constraints

- Windows x64, application sans privilèges administrateur.
- Aucun cloud pour l'audio, les vidéos et la transcription.
- Les effets sont indépendants : couper les effets n'arrête pas l'enregistrement.
- Aucun raccourci global activé sans choix explicite de l'utilisateur.
- Coordonnées physiques des moniteurs, y compris origines négatives et DPI mixtes.
- Preserve existing REA configuration, targets and raw evidence.

## Review Focus

- Negative monitor coordinates and DPI changes preserve cursor/effect alignment.
- Invalid or truncated settings recover without losing the original file.
- Starting or stopping capture twice cannot orphan recorders or lose a playable take.
- Silence, device removal and encoder failure preserve duration and recoverable media.
- Subtitle edits, punctuation and paths with spaces produce valid timed exports.
